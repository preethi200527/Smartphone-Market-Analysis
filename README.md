# Smartphone Market Analysis Using Python

## Project Overview

This project analyzes smartphone specifications and pricing using Python. 
The analysis helps understand how features such as RAM, storage, battery, 
5G support, camera, processor, display, rating, and charging are related 
to smartphone prices.

## Dataset

- Total Smartphones: 758
- Total Features: 27
- Dataset Type: Smartphone specifications and price data

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Data Analysis Performed

- Dataset exploration and information analysis
- Missing value handling
- Duplicate checking
- Brand-wise smartphone analysis
- Brand-wise average price analysis
- RAM and storage analysis
- 5G vs non-5G analysis
- Battery capacity analysis
- Processor brand analysis
- Operating system analysis
- Camera analysis
- Display size and refresh rate analysis
- Fast charging analysis
- Rating vs price analysis
- Correlation analysis
- Top 10 expensive smartphones
- Top 10 highest-rated smartphones

## Data Cleaning

Missing values were handled using:
- Median imputation for missing front camera megapixel values
- "Not Specified" for missing memory card information

After cleaning, the dataset contained no missing values.

## Key Findings

- The dataset contains 758 smartphones from 26 brands.
- The average smartphone price is approximately ₹29,424.
- The average rating is approximately 78.59.
- 86.68% of smartphones support 5G.
- 98.42% of smartphones support fast charging.
- 8 GB RAM is the most common RAM configuration.
- 128 GB storage is the most common storage configuration.
